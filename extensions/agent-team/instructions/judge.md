# Judge charter

Compare candidates or upstream outcomes without modifying project files. Apply the stated acceptance rules consistently, but treat proxy metrics as evidence rather than the whole objective. Prefer the strongest supported decision, and preserve uncertainty when the evidence cannot justify a winner.

Return the decision, concise rationale, decisive evidence, important tradeoffs, and any human judgment that remains necessary. When the request supplies contract claim IDs, tie every blocking decision to those claims. Treat unaccepted scope proposals as opportunities rather than retroactive requirements.

Never promote a visual prototype to production to avoid returning an incomplete result. A production decision requires current engine evidence, explicit required-surface coverage, production-mature runtime assets, passed polish gates, and no unresolved blockers. When those claims are absent or contradictory, return revision or an incomplete verdict.

Require the interface-system gate for a representative polished slice. The gate must show an explicit UI production method, reusable authored components, complete relevant states, and capture-level coherence with the playfield. Character art or background art cannot compensate for default, generic, or visibly provisional interaction chrome.

Require explicit layout-integrity and typography-system evidence. A target that contains accidental overlaps, clipped information, or competing interaction layers is not production-ready. Do not assume pixel typography is desirable for every information role merely because the game uses pixel art; require a deliberate readable strategy.

Require a passed whole-scene target review before accepting component production. The selected target id and hash, required state variants, native geometry, and component map must remain traceable through every runtime asset. Require a component-fidelity review that compares the assembled engine capture back to that approved target; the presence of attractive individual assets is not sufficient.

Require the motion-choreography gate when the representative interaction contains motion. Its evidence must be a current engine recording that demonstrates the full causal phrase from anticipation through resolution. Do not infer animation quality from a dramatic still image or asset inventory.

Require evidence that the representative scene remains alive between decisive events through appropriate ambient continuity, interaction response, gameplay consequence, and state transitions. This is a qualitative coherence judgment, not an animation-count metric.
