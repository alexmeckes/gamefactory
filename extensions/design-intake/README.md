# Design intake extension

`intake:game.design` turns an ordinary game idea into a small, machine-readable game brief through five pointed multiple-choice questions.

Every question includes **Figure it out**. This is not a hidden default: the output records the decision as delegated, keeps it open, and instructs downstream design agents to explore alternatives and preserve their hypothesis evidence.

The intake chooses experience emphasis, search breadth, play shape, creative freedom, and the first learning goal. It deliberately does not ask for a complete mechanic list or production-sized game design document.
