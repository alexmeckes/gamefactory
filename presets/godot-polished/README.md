# Godot polished v2 project

This preset begins with an embodied experience proof and refuses to promote proxy gameplay or a hybrid visual state.

Start from `project.template.json`. Its preproduction campaign uses `converge-game-spec` to freeze only the claims required by the next slice. `embodied-campaign.template.json` owns the first acceptance boundary: one small, experiential runtime loop before art direction or asset production. The dependent production campaign may proceed only from that accepted revision. Each slice receives an enforced `projectSlice` contract with consumed claims, player outcome, primary risk, non-goals, mutation paths, evidence gates, and bounded retry ownership. Runtime evidence may trigger one explicit return edge to spec convergence; ordinary implementation or presentation defects stay inside the slice repair graph.

The embodied slice asks Sol/xhigh to plan a player-complete slice, then builds and repairs one runtime prototype before visual direction begins. The prototype must use shipping Godot InputEvents, a visible player actor, measured movement, spatial interaction, player-caused state consequence, and changing continuous engine frames. A factory-owned black-box probe outside the candidate project injects configured `InputMap` actions and observes configured nodes and consequence properties; game agents do not write their own proof harness. Direct helper replay, invisible coordinates, changing text over a static scene, and monolithic generated scene plates fail the machine gate. Luna/high handles bounded investigation and criticism with a Sol advisor available; Sol/medium builds the embodied prototype; Sol/xhigh makes the promotion decision.

The dependent production slice does **not** rebuild that core. It starts by rerunning the trusted Godot probe against the promoted revision, then one Sol/xhigh screen-directing writer establishes the visual system and whole-scene targets. A target approval gate selects one decomposable direction. The asset-lane planner returns one explicit outcome, and graph `when` conditions prevent unselected SAM3, Omni, tracking, or pixel-compilation providers from starting. After integration, a second factory-owned Godot evidence node supersedes the baseline trace. Gemini reviews only this current post-integration frame sequence and trace; the final Sol judge combines that multimodal review with deterministic engine, hash, design-system, artifact-lineage, and runtime-consumer checks. The production graph deliberately has no duplicate core director, prototype builder, evidence auditor, component critic, or art-director critic.

Gemini Flash supplies two independent multimodal reviews without adding a tournament: an embodied-readability checkpoint in the core slice and a production checkpoint after the post-integration Godot refresh. The first blocks only unreadable or static pseudo-play; the second treats blocker and major presentation defects as repairable failures. Findings cite exact evidence and identify whether ownership belongs to implementation, the approved target, or the GameSpec. Both remain subordinate to deterministic Godot proof and the Sol judge.

Whole-screen images remain useful after the embodied prototype passes, but only as reviewed art-direction targets. Their component maps must keep environment layers, actors, interactive props, effects, and UI independently renderable and animatable in the engine. The production writer may not replace the live scene with the approved screenshot.

`evaluator:design.system` independently validates the candidate's `gamefactory.polish-readiness/v1` manifest. A production slice fails when a required surface is prototype, placeholder, or omitted; a runtime asset is only reference, source, extracted, or engine-ready; a required polish gate lacks pinned evidence; a blocker remains; or the claimed capture is not a hashed engine-captured production target.

Copy the templates as `gamefactory.project.json`, `concept.md`, `game-spec.json`, `spec-campaign.json`, `embodied-campaign.json`, `campaign.json`, and `factory.json`. Replace all ids, contract placeholders, and the small `embodiedProbe` node/action/property map before launch; unresolved `__REPLACE_*__` bindings fail before engine work. Slice `mutablePaths` are mandatory and must be no broader than the campaign boundary. Evidence gates accept only references to preserved artifacts, not booleans or proxy metrics. Frozen specs are archived with SHA-256 lineage under the factory data root.
