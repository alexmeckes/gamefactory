# Pixel production direction

Use a cohesive authored pixel-art language suitable for a native 480×270 canvas and integer scaling. The game concept, fantasy, palette, materials, silhouettes, composition, and UI motif are open creative decisions.

Design whole gameplay screens and their state variants before producing individual components. Approve a clear scene target, then derive every runtime sprite and interface element from that target with consistent pixel density, border weight, typography scale, spacing, and palette. Generated images are references or source material until they are cleaned, compiled to native dimensions, integrated, and verified in the running engine.

Avoid programmer chrome, default controls, mixed resolutions, arbitrary stretching, decorative clutter, static paper-doll action, and concept-art imagery masquerading as a playable screen. Motion must communicate anticipation, action, impact, reaction, and resolution where the mechanic calls for them.
