# Fresh game boundary

This repository is deliberately not a game yet. Invent a new compact concept rather than extending or remixing any existing GameFactory title.

The finished slice should have one immediately understandable player verb, one meaningful decision that changes the outcome, one short deterministic encounter, and clear planning/action/result states. Keep the playable scope small enough to polish completely. Prefer surprising systemic depth over content volume. Do not build an autobattler unless the discovered mechanic genuinely requires one.

The baseline is only a runnable measurement shell. Replace it freely. Preserve the `factory_setup`, `factory_tick`, `factory_sample`, and `factory_collect` contract so the real Godot scenario remains deterministic and reports honest causal telemetry.

No synthetic score is evidence that the game is fun. Report what the engine proves and leave human enjoyment as an explicit follow-up question.
