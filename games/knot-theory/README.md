# Knot Theory

A mouse-first Godot puzzle game about manipulating one continuous rope.

Open `project.godot` in Godot 4 and run the project. Drag the rope directly;
in the baseline loom, `P` pins the grabbed point and `R` resets. The factory
campaign replaces this loom with competing playable vertical slices.

From the repository root:

```powershell
npm run factory -- doctor games/knot-theory/campaign.json --config games/knot-theory/factory.config.json
npm run factory -- run games/knot-theory/campaign.json --config games/knot-theory/factory.config.json
```
