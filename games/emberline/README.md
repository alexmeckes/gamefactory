# Emberline

Mouse-first Godot tower defense about composing heat reactions along a living
fuse. Click to begin, choose an instrument, place it in a brass socket, and
ignite the next wave. `R` restarts and `Space` starts a ready wave.

The factory campaign uses real Codex App Server agents, candidate-specific
ImageGen-assisted design systems, engine-native captures, visual review, and
deterministic Godot scenarios.
