# Root & Ruin

A gameplay-first fantasy autobattler slice for GameFactory.

Rotate plant root ports during planning, then start the battle. Water from the spring powers connected plants, but blight can propagate across those same roots. The initial slice asks whether containment is a legible and satisfying formation decision.

Controls:

- Click a plant during planning to rotate its root ports.
- Press Space or click **Begin battle** to start.
- Press R or click **Reset round** to restore the current encounter.

The first phase intentionally uses only procedural Godot rendering. See `GAME.md` for its evidence boundary.
